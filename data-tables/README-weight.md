# Веса опор (лист «Вес»)

**Полные правила проекта «Масса»:** см. **[docs/правила-проект-масса.md](../docs/правила-проект-масса.md)**.

На листе **«Вес»** в Google-таблице выводятся **две колонки веса** для сверки:

- **Вес (ПК), кг** — из **ПК** (прайс с картинками xlsx → `weight_user.csv`) и из **«Для прайса»** (`Прайсы/Для прайса` — нормативные xlsx)
- **Вес (каталоги), кг** — из **всех** `data/weight_sources_*.csv` (объединённый справочник; при дубликате приоритет у ОСТ 36-146-88)

## Как выглядит таблица

| A — Название опоры | B — Вес (ПК), кг | C — Вес (каталоги), кг |
|--------------------|------------------|-------------------------|
| 57-КХ-А11           | 2.1              | 2.2                     |
| 159-ХБ-А            | 2.05             | 1.8                     ← **подсвечены только B и C** (расхождение >5%) |
| …                   | …                | …                       |

- **Колонка A** — всегда без заливки.
- **Колонки B и C** — подсветка: при весе ≥1,5 кг — расхождение >5%; при весе <1,5 кг — >15%. ХБ до 45 диаметра не выделяются. Старые правила условного форматирования при выгрузке удаляются.

## Источники первой колонки (Вес (ПК), кг)

- **ПК** — xlsx: **Прайсы/прайс с картинками (1).xlsx** (или `data/...`). Веса извлекаются по листам КХ, КП, ХБ, ТХ, ТО в `data/weight_user.csv` (`extract_pk_weights.py`). Ручные исправления — в `PK_WEIGHT_CORRECTIONS`.
- **Для прайса** — папка **Прайсы/Для прайса** (нормативные xlsx). При каждой выгрузке, если xlsx в папке новее `weight_dlya_prajsa.csv`, он перезаписывается автоматически (`ensure_up_to_date()`). Первая колонка собирается из ПК с подстановкой недостающих весов из этого CSV.
- Папка **РК** — для чертежей, не для прайсов. Список опор — **`agent_weight_names.txt`**. При выгрузке `write_pdf_zmk.py` сначала обновляет веса из ПК, затем пишет лист «Вес».
